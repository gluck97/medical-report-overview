包含检查与治疗时间线、指标趋势、原报告参考范围、预期与历史对照、影像对照及报告原件。支持电脑和手机阅读。

此仓库保存由本地主记录生成的发布副本；原件按原目录保留，复制前后通过 SHA-256 校验。网页显示的资料截止日、记录更新日和原件校核日分别保留，不用部署日期替代检查日期。

本次包含 32 组记录、48 项数值指标及 35 个原件。发布清单见 `release.json`。

## 后续更新

在本地维护主记录、参考范围、预期版本和原件，运行“生成GitHub发布包.py”，核对后提交本目录并推送到 `main`。GitHub Pages 从 `main` 分支根目录自动发布。网页不自动获取医院报告。
